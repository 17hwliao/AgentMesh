# S3.5b 客户端接入与回滚

**依赖** 已验收的 S3.5a 扫描；自动写入依赖 [目录锁与加密快照](design-s36-backup.md)。

- 第一交付生成可复制的网关接入片段，使用模型公开 ID 和环境变量引用，显示目标客户端的协议兼容范围。无可验证的协议支持时只展示手动接入信息。
- 自动写入最多选一个经过实测的 Adapter；当前先验证 OpenCode 专用配置是否适合。选定后记录格式、支持版本与最小字段集合，再接入管理页。
- 预览生成限时、单次使用的 `plan_id`，绑定管理员会话、目标文件身份、原哈希和候选哈希；UI 只展示脱敏 diff。应用时显式确认并重验计划、原文件哈希、权限与目标路径。
- Adapter 通过白名单决定写入目标。确认本机 Agent 状态、文件身份、ACL 和重解析点边界后创建加密原文快照，再按 Windows 支持的替换方式写入与校验。对未知格式、并发修改、运行状态不明确或无法保留权限的情况停止应用。
- 回滚需确认当前文件仍匹配写入后哈希；存在用户后续修改时报告冲突。审计仅记录动作、结果、计划和快照标识。

**验收** 片段能接入已受支持客户端。已写入的单 Adapter 覆盖预览后漂移、替换失败、ACL 保留、重解析点拒绝、回滚冲突以及 diff 与日志密钥隔离。
