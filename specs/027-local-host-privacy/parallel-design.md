# S3.5 并行开发设计

**日期** 2026-11-19

**集成分支** `codex/local-host-privacy`

沿用 [决策 007](../../decisions/007-local-host-subscription-privacy.md) 和 [027 规格](spec.md)。先闭环单机发现，再并行推进能独立测试的功能。集成和验收由主对话负责人统一处理。

## 先收口 S3.5a

S3.5a 已通过 [Windows 自动验收](../../docs/acceptance/S3.5a.md)。记录覆盖 Ollama 与 LM Studio mock 发现、兼容转发、重启持久化及扫描和目录失败边界。后续任务见 [任务清单](tasks.md)。

## 工作分配

| 分稿 | 可独立交付 | 集成依赖 |
| --- | --- | --- |
| [S3.5b 客户端接入](design-s35b-agent-connect.md) | 配置片段、配置计划和文件测试 | 已验收的扫描结果；自动写入依赖锁与加密快照 |
| [S3.5c 隐私](design-s35c-privacy.md) | 脱敏规则、协议适配、流测试 | 统一 Key 策略、出站钩子和审计字段 |
| [S3.5d 订阅](design-s35d-subscription.md) | 上游授权核验、mock 生命周期 | 身份范围和候选逐跳校验；真实接入受授权门槛约束 |
| [S3.5e 局域网](design-s35e-lan.md) | 监听校验、TLS、设备 Key 和双机验收清单 | 明确入口身份和可共享模型权限 |
| [S3.6 备份](design-s36-backup.md) | 目录锁、归档格式、失败恢复测试 | 隔离测试可先行；对外恢复入口统一集成 |

配置片段、隐私纯逻辑、LAN 监听校验和备份锁可各自推进。订阅先做协议与授权核验，避免成为其他工作阻塞项。优先合入目录锁和加密快照能力，再启用配置自动写入；完整备份仍单独验收。

## 共享代码归属

- 集成负责人统一处理 `cmd/api`、管理路由与 UI 导航、SQLite 迁移编号和任务勾选。工作项各自提交独立包、测试和明确的接入接口。
- 鉴权策略使用显式 Key 类型、来源和服务端策略；模型可见性、直接路由和每次 fallback 使用同一权限约束。选择顺序和运行计数继续沿用现有网关。
- 每项提交对应自动测试、失败路径和验收说明。只有本地模拟结果时如实标记；真实 LAN 和订阅接入分别记录实际验证。公网安排在后续版本。
