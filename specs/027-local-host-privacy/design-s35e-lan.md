# S3.5e 局域网数据面

**依赖** 显式设备 Key 类型、模型白名单和来源策略。接入可共享的 API 或本地模型即可完成验收。

- 保持管理端 loopback。数据端在用户明确开启 LAN 后绑定选定的 RFC1918 接口地址；拒绝通配、公网地址和未识别的接口。公网部署保留在后续阶段。
- LAN 数据端默认要求 TLS，远程客户端信任指定 CA 或受信任证书。跳过证书验证只适用于受控 loopback 测试。限流按实际连接来源处理。
- 设备使用独立 Key，管理员可限制模型并单独撤销；撤销后的新请求立即拒绝，已开始输出的 SSE 自然结束或达到既有超时。目录、直连、路由组和回退共享同一候选权限检查。
- 为设备说明 Base URL、证书信任、授权模型和 Key 连接方式。管理接口和主机扫描均留在本机控制面。

**验收** 自动覆盖默认拒绝 LAN、监听地址校验、证书失败、管理路由隔离及设备 Key 撤销。同网第二台设备完成 HTTPS 流式调用、验证无法访问管理面、验证另一个设备 Key 仍有效后，才记录真实 LAN 通过。
