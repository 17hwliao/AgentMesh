# S3.5d 本机订阅实验

**依赖** 上游正式授权和调用方式通过核验，网关具备显式本机身份及逐候选权限检查。订阅功能默认关闭。

- 为每个候选提供方记录受支持的授权渠道、允许用途、范围、刷新所有者、撤销方式与额度来源。资料不足时保留实验设计和 mock 测试；真实调用保持关闭。
- 仅由本机用户通过服务商支持的流程显式启用。账号发现不读浏览器、其他客户端登录文件或凭据库；优先使用官方托管会话引用，避免复制或备份长期凭据。
- 一个账号映射到一个 Provider，复用现有模型、冷却和路由组。公开模型 ID 来自稳定 slug，区域或套餐不可验证时按未知显示。
- 状态包含待授权、可用、待重新授权、冷却与已撤销。并发刷新合并为单次操作，失败退避；撤销后重新生成快照并拒绝新调用。
- 订阅从本机入口和显式本机凭据双重校验，设备 Key 的目录、直连请求和每一跳 fallback 均排除订阅候选。

**验收** mock 验证授权状态流转、并发刷新、撤销、设备 Key 拒绝和日志无凭据。真实账号接入单独记录官方依据与用户授权的联调结果。
