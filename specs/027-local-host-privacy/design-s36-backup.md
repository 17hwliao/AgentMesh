# S3.6 加密备份与离线恢复

**依赖** 现有 SQLite catalog 与密钥文件。目录锁和加密配置快照可以先集成，供 S3.5b 复用。

- 锁覆盖同一数据目录的运行、备份和恢复互斥边界。打开时按实际文件身份获得锁，使用同一协议处理进程退出和故障，Windows 上验证两个进程竞争同一目录。
- 归档使用版本化 `.agmbackup`。随机数据密钥加密目录快照和匹配的主密钥，独立派生或封装密钥保护数据密钥，认证归档头和清单。口令通过安全交互输入；跨机口令模式与后续同机系统保护模式分开。
- SQLite 使用一致性快照，归档排除临时文件、第三方登录凭据及脱敏映射。配置回滚快照单独加密；管理页面和日志只显示非敏感元数据。
- 离线恢复先校验归档版本、认证、条目边界、SQLite 完整性和密钥配对，再准备受权限保护的同卷临时目录。保留原目录并记录恢复阶段；故障后可以回到旧目录或继续校验。
- 旧明文目录仅走显式兼容导入，报告其风险；生产新归档走加密格式。

**验收** 验证正常恢复后原有设备 Key 和可托管 Provider 可用，错误口令、篡改、截断、异常条目、锁冲突、磁盘不足或中断时旧目录仍可使用。
