## 1. 定位

S3.5 在现有 AgentMesh 数据面和控制面之上，增加本机资源发现和可管理的模型来源。

它不是：

- HTTP 反向代理。
- 透明 MITM。
- 操作系统沙箱。
- 完整 DLP 产品。
- 订阅账号池或账号共享服务。

S3.5a 只交付只读宿主发现、Ollama/LM Studio 发现和本地模型目录。订阅账号、配置文件自动改写、隐私脱敏、真实局域网和完整备份硬化分别留到后续阶段。

## 2. 三类对象

| 对象 | 含义 | 是否进入 Provider |
| --- | --- | --- |
| 本机 Agent 安装 | Codex、Claude Code、Gemini CLI、OpenCode 等客户端 | 否，除非另有可验证调用协议 |
| 订阅账号 | 用户本机已登录的账号凭据来源 | 仅通过默认关闭的实验适配器 |
| 模型来源 | API Provider、本地模型服务、远程 AgentMesh | 是 |

Agent 是客户端，不是 Provider。

## 3. 不变量

1. 控制面写配置，数据面从不可变 Snapshot 读取路由和策略。用量、审计、最后使用时间和冷却继续走独立运行状态。
2. 公共模型 ID 使用稳定的 `<provider-slug>/<upstream-model>`。
3. 扫描默认只读，不执行扫描到的二进制，不读取浏览器凭据。
4. 订阅适配器默认关闭，默认 local-only，不允许局域网/公网共享。
5. 配置自动写入必须经过 plan、hash、确认、备份和 rollback 检查。
6. 隐私层默认 off，失败时不能静默明文透传。
7. 管理面保持 loopback；真实 LAN 必须显式启用。
8. 本地模拟不能写成真实设备、公网或生产发布。

## 5. S3.5a 详细范围

### 5.1 宿主 Agent 只读扫描

第一版发现：

- Codex；
- Claude Code；
- Gemini CLI；
- OpenCode。

扫描来源仅限：

- PATH 中的绝对目录；
- 已知用户配置目录；
- 用户显式添加的根目录。

扫描只返回安装状态、可执行文件是否存在、已知配置目录是否存在、可读性和最后修改时间。第一版不解析登录凭据，不返回 token、Cookie 或完整配置正文。

拒绝：

- 相对 PATH 项和 UNC 路径；
- symlink、Windows junction、reparse point；
- 浏览器 Cookie、密码库和无关目录；
- 超出文件数和深度上限的递归扫描。

### 5.2 Ollama / LM Studio

只接受 loopback endpoint：

- Ollama：`http://127.0.0.1:11434`，模型发现使用 `/api/tags`。
- LM Studio：`http://127.0.0.1:1234/v1`，模型发现使用 `/models`。

发现结果只读；用户确认导入后才创建或复用 Provider：

- Provider 类型分别为 `ollama`、`lmstudio`。
- 本地默认无认证。
- 新模型默认禁用。
- discovery 不覆盖手工能力字段。
- 模型消失只标记 stale。

聊天继续走现有 OpenAI 兼容路由和 Snapshot；Ollama 使用其 `/v1` 兼容端点。若本机 Ollama 版本不支持该端点，测试必须受控失败，不能回退到未声明的原生协议。

### 5.3 管理 API

```text
GET  /admin/host/agents
POST /admin/host/scan
POST /admin/host/local-models/scan
POST /admin/host/local-models/import
```

所有接口继续使用管理 session、CSRF、Origin 校验和 loopback listener。扫描错误返回稳定错误码，不在日志或响应中输出凭据。

### 5.4 验收

必须覆盖：

- 已知 Agent 安装和 PATH 发现。
- symlink/junction/reparse 拒绝。
- 不执行二进制、不读取浏览器凭据的静态检查。
- Ollama `/api/tags` 和 LM Studio `/v1/models` mock 发现。
- 只接受 loopback endpoint。
- 导入后 Provider/模型持久化，新模型默认禁用。
- 重复发现不覆盖手工能力字段，缺失模型标 stale。
- 重启后 Provider 和模型仍存在。
- 不出现 token、Cookie 或完整配置正文。

## 6. 后续阶段边界

### S3.5b 配置接入

先生成可复制片段；自动写入最多一个 Adapter。需要 `plan_id`、`expected_hash`、allowlist、ACL、运行中检测、加密快照和 rollback。

### S3.5c 隐私

只做 JSON 字符串值替换；覆盖 Chat delta、tool call arguments 和 Responses 事件。不能承诺完整 DLP。

### S3.5d 订阅

默认关闭实验能力；一个账号一个 Provider；local-only；刷新单飞、撤销、失败冷却和条款提示。没有稳定条款和撤销路径时不进入默认路线。

### S3.5e 局域网

新增显式 `AllowLANListen`，管理面继续 loopback；真实双机验收。公网和生产 TLS 不在本阶段。

### S3.6 备份

先保证配置快照加密，再实现版本化 `.agmbackup`；恢复必须离线、预检、校验和原子替换。

## 7. 当前限制

- S3.5a 只证明本机 mock 和 loopback 发现，不代表真实 Agent 配置可用。
- Ollama/LM Studio 的真实版本差异必须通过独立联调记录，不能从 mock 推导。
- 订阅、自动配置写入、隐私脱敏、真实 LAN 和公网均未在 S3.5a 交付。
