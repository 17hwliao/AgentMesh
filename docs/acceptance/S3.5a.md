# S3.5a 本机发现与本地模型目录验收

**日期** 2026-11-19

**分支** `codex/local-host-privacy`

**验收范围** Windows 自动测试、临时 SQLite、loopback HTTP mock 与本地文件测试。

## 行为证据

| 用例 | 结果 |
| --- | --- |
| 宿主扫描 | 临时目录发现安装与配置元数据。相对路径、UNC 和模拟重解析点被跳过，PATH 搜索受根目录和候选上限约束，超时返回截断结果。 |
| 管理接口 | 匿名读取、缺失 CSRF 和错误 Origin 被拒绝。扫描响应不含测试凭据文件名称或内容。 |
| Ollama 和 LM Studio | 分别用 `/api/tags` 与 `/v1/models` 发现。导入需要显式确认，服务端重新发现，模型默认禁用。 |
| 本地模型边界 | 拒绝非 loopback 地址、无效 URL 和重定向。超出 1 MiB 的目录返回稳定错误。无效 URL 与原始上游错误正文不回显。 |
| 数据面闭环 | 通过内部模型 ID 启用后，持 local Key 调用公开模型 ID。兼容上游收到 `/v1/chat/completions` 且无 Authorization，客户端收到文本与 SSE `[DONE]`。禁用和 stale 模型未到达上游。 |
| 刷新与重启 | 空或失败的目录保留现有模型。成功的非空刷新标记缺失模型为 stale，保留手工能力字段。关闭后重开同一数据目录，模型 ID、启用状态与 stale 状态仍在，原 local Key 仍能调用。 |

## 复验

```powershell
$env:GOMAXPROCS='2'
$env:GOMEMLIMIT='3GiB'
go test -count=1 ./internal/hostscan ./internal/localmodels ./internal/catalog ./internal/standalone
go test -count=1 ./...
go vet ./internal/... ./cmd/api
go build -o NUL ./cmd/api
node --check internal/standalone/ui/app.js
git diff --check
```

以上命令均通过。全仓 Go 测试包括本次 Windows 的 `cmd/local-benchmark`，差异检查仅有 Git 的 LF/CRLF 提示。

当前记录使用 Ollama、LM Studio 协议 mock 与临时扫描夹具。真实安装版本、Windows 实际 junction、浏览器手动操作、真实局域网和订阅接入均未在本次验证中执行。
