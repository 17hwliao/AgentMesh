## 真实联调前置条件

使用同一 Clerk 应用的 Development 实例即可在本机联调，无须先购买云服务器或配置生产 DNS。配置公开 Publishable Key、对应实例地址、服务端 Secret Key 的本机私有文件路径；用户成功登录后，使用稳定的 `user_…` ID 绑定已有网关租户和专用应用 Key。密钥文件、成员映射不加入 Git。

真实身份配置缺失时保持拒绝访问；不增加免登录入口或用预览模式绕过认证。Clerk 开发者账号若被拒绝，需要先由账号持有人解决注册访问问题。

沿用原始 20 元累计预算账本。开始前确认累计已知费用和未决预留，再限制本轮调用次数及输出 token；未知费用继续保守占用预算，不重置账本。供应商价格估算、网关钱包与实际平台账单分别记录。

取得配置后验证：实际登录和邮箱状态 → 获准租户/识图模型 → 上传固定测试图 → 私有引用到真实模型 → SSE 完整回答 → 用量、扣款与冻结释放 → 图片历史追问。非法图片、无视觉能力、跨租户等拒绝路径先在零费用测试验证，真实调用保持最少必要次数。
